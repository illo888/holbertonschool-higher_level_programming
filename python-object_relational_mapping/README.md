# Python - Object-Relational Mapping

This project explores the connection between Python and MySQL databases, implementing both raw SQL queries with MySQLdb and the SQLAlchemy ORM framework.

## Overview
The project demonstrates the transition from traditional SQL queries to Object-Relational Mapping, showcasing how ORM abstracts database operations into Python object manipulations.

## Technologies Used
- Python 3.8.5
- MySQLdb module 2.0.x
- SQLAlchemy 1.4.x
- MySQL 8.0

## Learning Objectives
- Connecting to MySQL databases from Python scripts
- Executing SELECT, INSERT, UPDATE, DELETE operations
- Understanding and implementing ORM concepts
- Mapping Python classes to MySQL tables
- Preventing SQL injection attacks

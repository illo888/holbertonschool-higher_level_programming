# JavaScript - Warm Up

## Project Overview

This project introduces fundamental JavaScript programming concepts through systematic implementation of core language features and best practices.

## Technical Objectives

- Master variable declaration patterns (const, let)
- Implement control flow structures (conditional statements, loops)
- Develop function composition and recursion techniques
- Utilize process arguments for command-line interaction
- Apply module export patterns for code organization
- Demonstrate proficiency in JavaScript data structures

## Technical Requirements

- **Runtime Environment**: Ubuntu 20.04 LTS with Node.js v14.x
- **Code Standards**: Semistandard compliance (StandardJS + semicolons)
- **File Permissions**: All scripts executable with proper shebang
- **Module System**: CommonJS exports pattern

## Learning Outcomes

Through progressive task implementation, this project establishes foundational competency in:
- JavaScript syntax and semantics
- Functional programming paradigms
- Command-line argument processing
- Modular code architecture
- Recursive algorithm design

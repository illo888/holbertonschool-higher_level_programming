# SQL - More Queries

This project covers advanced SQL concepts including user management, privileges, constraints, and JOIN operations.

## Learning Objectives
- Creating and managing MySQL users
- Understanding and implementing privileges
- Working with PRIMARY KEY and FOREIGN KEY constraints
- Using NOT NULL and UNIQUE constraints
- Retrieving data from multiple tables using JOINs
- Implementing subqueries for complex data retrieval

## Technologies
- MySQL 8.0
- Ubuntu 22.04 LTS
